# Joleen — Portfolio

React + Vite portfolio site.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Live site (GitHub Pages)

After push to `main`, GitHub Actions deploys to:

**https://joleen-kujoo.github.io/Joleen-sDesign/**

In the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions** (enable once if the first deploy does not start).
