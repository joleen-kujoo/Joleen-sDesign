不用找验证码 — 3 步上传

Token 只在本机粘贴，不要发给任何人或 AI 聊天。

第 1 步：点下面按钮，在 GitHub 页面最底下点绿色 Generate token，复制那一长串（只显示一次）。

打开：创建 Token

第 2 步：在 Cursor 里按 Cmd + J，点下面的 Terminal，复制下面黑框里的命令，粘贴后回车： 
cd ~/Developer/hgy-portfolio
git push -u origin main
第 3 步：终端会问密码：
  • Username → 填 joleen-kujoo
  • Password → 粘贴第 1 步的 Token（不是登录密码）
没有报错就是上传成功。然后去 Cloudflare 看 Deployments 是否在构建。

说明：浏览器里的「8 位验证码」只在运行 gh auth login 时出现在终端；你走上面流程可以完全不用验证码。
